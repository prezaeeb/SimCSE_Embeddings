This is the code used for the article "Detecting Online Grooming By Simple Contrastive Chat Embeddings"
https://dl.acm.org/doi/abs/10.1145/3579987.3586564


The Problem: This code proposes a contrastive learning framework for feature extraction in a sentence-based manner, where it can assign a feature vector to the conversation with misspellings using subword information.
It proposes a configuration of RoBERTa encoders and supervised SimCSE for training the SVM model, leading to a high rate of detecting relevant samples (predatory samples).
